Kia ora, this is the Aotearoa music explorer project. 

Basically, the concept is to help people uncover new artists from Aotearoa, New Zealand. This is basically a project/idea that I had during NZ Music Month. 

I know Spotify isn't the greatest platform for supporting artists, but in time I will add elements to help support any featured artists better e.g. other platforms like Bandcamp and possibly an explore merch/links to shopts etc. 

YouTube/music videos as well is another thing I'll get too at some point. 

It's a foundation platform that will evolve or get dusty and fade into nothing over time. 

Feel free to let me know if you have any ideas.
